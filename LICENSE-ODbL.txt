=======================================================================

This repository contains OpenStreetMap material. Specifically, the following
files contain OpenStreetMap tags, or venue categories abstracted from the
OpenStreetMap POI classification:

    map/city_map.sql                      OpenStreetMap tags
    map/map.lua                           OpenStreetMap tags
    map/export_city.py                    tag-derived category names
    custom_settings.py                    tag-derived venue categories (POI_INCLUDE)
    src/simulation/semantic_enrichment.py tag-derived venue categories
    src/spatial/region_representation.py  tag-derived venue categories
